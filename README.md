# 🏁 LMU Race Control — Mesa de Transmissão para Narradores

Mesa de controle e telemetria em tempo real para transmissões do **Le Mans Ultimate (LMU)**.

## 🚀 Início Rápido

1. **Iniciar Backend:**
   ```powershell
   cd backend
   python server.py
   ```
2. **Abrir a Interface do Narrador:**
   Abra o arquivo `frontend/index.html` no seu navegador (Chrome, Edge, Firefox) ou adicione como fonte de navegador no OBS Studio.
